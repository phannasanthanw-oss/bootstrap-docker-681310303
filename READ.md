# 🚀 Personal Web Project (Bootstrap 5 + Docker)

โปรเจกต์พัฒนาเว็บไซต์ส่วนตัวด้วย **Bootstrap 5**, **Vite** และรันผ่าน **Docker Desktop**

## 🛠️ Tech Stack
* **Frontend:** Bootstrap 5.3, Sass/SCSS, HTML5
* **Build Tool:** Vite
* **Containerization:** Docker Desktop & Docker Compose
* **Environment:** Node.js 20 (Alpine)

## 💻 วิธีการรันโปรเจกต์บนเครื่องใหม่ (How to Run)

1. เปิดโปรแกรม **Docker Desktop**
2. Clone โปรเจกต์นี้ลงเครื่อง:
   ```bash
   git clone [https://github.com/SarayutThibhodee/bootstrap-docker-assignment.git](https://github.com/SarayutThibhodee/bootstrap-docker-assignment.git)
   cd bootstrap-docker-assignment
